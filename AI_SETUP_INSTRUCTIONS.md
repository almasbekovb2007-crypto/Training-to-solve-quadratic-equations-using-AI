## Настройка DeepSeek или другого AI-провайдера для анализа фотографий

### 📝 Шаги для включения ИИ анализа:

#### 1. Получить API ключ DeepSeek
- Получите API ключ у DeepSeek
- Скопируйте ключ, он больше не будет виден

#### 2. Обновить конфигурацию приложения
Откройте файл `lib/core/constants/app_constants.dart` и замените:

```dart
static const String aiProviderKey = 'your-deepseek-api-key-here';
```

На:

```dart
static const String aiProviderKey = 'YOUR_DEEPSEEK_API_KEY';
```

#### 3. Убедиться, что зависимость `dio` добавлена
В `pubspec.yaml` должна быть зависимость:

```yaml
dependencies:
  dio: ^5.3.2
```

#### 4. Тестирование

1. Запустите приложение
2. Перейдите на экран "Анализ решения по фото"
3. Загрузите фото решения квадратного уравнения
4. Нажмите "Анализировать"

### ⚙️ Что происходит при анализе:

1. **Валидация изображения** - проверка качества фото (разрешение, яркость, контрастность)
2. **Отправка на DeepSeek / AI-провайдера** - фото и текст вашего уравнения отправляются в облако
3. **Анализ ИИ** - модель DeepSeek анализирует решение и проверяет его правильность
4. **Получение результата** - результат анализа отображается в приложении

### 📊 Формат ответа ИИ:

```json
{
  "isCorrect": true/false,
  "feedback": "Краткий отзыв",
  "errors": ["ошибка 1", "ошибка 2"],
  "confidence": 0.95,
  "analysis": "Детальный анализ"
}
```

### 🔒 Безопасность:

⚠️ **ВАЖНО**: Не сохраняйте API ключ в публичных репозиториях!

**Для production используйте:**
- Переменные окружения
- Secure configuration service
- Backend проксирование API запросов

**Пример с переменными окружения:**

```dart
// Загрузить из .env файла
import 'package:flutter_dotenv/flutter_dotenv.dart';

static const String aiProviderKey = String.fromEnvironment(
  'AI_PROVIDER_KEY',
  defaultValue: 'default-key',
);
```

### 💰 Стоимость:

- Использование DeepSeek / AI-провайдера платное
- Примерная стоимость зависит от вашего тарифного плана
- Мониторьте использование в панели управления DeepSeek или другом провайдере

### 🐛 Решение проблем:

**Ошибка: "Network error"**
- Проверьте подключение к интернету
- Убедитесь, что API ключ верный
- Проверьте лимиты API в панели управления DeepSeek или у вашего провайдера

**Ошибка: "Invalid response"**
- API ключ может быть неверным
- Проверьте формат JSON в ответе

**Ошибка: "Parse error"**
- Обновите версию пакета `dio`
- Проверьте логи консоли для подробной информации

### 📚 Дополнительная информация:

- Используйте документацию DeepSeek или вашего AI-провайдера
- Проверьте, какой формат запроса поддерживается для изображения и текста
- Настройте ключи и эндпоинты согласно документации вашего провайдера

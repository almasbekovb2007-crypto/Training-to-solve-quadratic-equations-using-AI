# Quadratic Equation Solver

Мобильное приложение для пше.

## 📱 Описание проекта

Приложение помогает школьникам и студентам изучать решение квадратных уравнений через:
- Интерактивный ввод коэффициентов
- Пошаговое решение с объяснениями
- Анализ фотографий решений с помощью ИИ
- Мультиязычную поддержку (русский, английский, кыргызский)

## 📋 Основной функционал

### 1. Решение квадратных уравнений
- Ввод коэффициентов a, b, c
- Валидация входных данных
- Мгновенное решение (< 1 секунда)

### 2. Пошаговое решение
- Формула дискриминанта: D = b² - 4ac
- Подстановка значений
- Вычисление дискриминанта
- Нахождение корней

### 3. Анализ изображений
- Загрузка фото решения
- Mock API для анализа
- Определение ошибок
- Правильное решение с объяснениями

### 4. Мультиязычность
- 🇷🇺 Русский
- 🇬🇧 Английский  
- 🇰🇬 Кыргызский

## 🧮 Математические формулы

### Дискриминант
```
D = b² - 4ac
```

### Корни уравнения
- **D > 0**: два действительных корня
  ```
  x₁ = (-b + √D) / (2a)
  x₂ = (-b - √D) / (2a)
  ```
- **D = 0**: один действительный корень
  ```
  x = -b / (2a)
  ```
- **D < 0**: нет действительных корней

## 🔧 API интеграция

### Mock API
Текущая версия использует mock данные для анализа изображений.

### Будущий API endpoint
```
POST /analyze
Content-Type: application/json

{
  "image": "base64_encoded_image",
  "equation": "ax² + bx + c = 0"
}
```

### Response
```json
{
  "errors": ["Ошибка в вычислении дискриминанта"],
  "correct_solution": "D = b² - 4ac = ...",
  "explanation": "Ты неправильно вычислил D",
  "is_correct": false,
  "confidence": 0.85
}
```
